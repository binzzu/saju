# 묘연의 연애사주 🐾

이름·생년월일·성별·태어난 시간을 적으면, 고양이 점술사 **묘연**과 조수 **코코**가
연애 중심 사주를 **웹툰**으로 풀어 주는 사이트예요.

- **내 사주** — 사주팔자 원국, 연애 캐릭터(일간), 오행 밸런스, 연애 스타일, 매력 신살(도화살·홍염살 등),
  배우자 자리와 이상형, 5년·12개월 연애운 달력, 개운법과 "연애 처방전"까지 8화 분량의 웹툰
- **궁합** — 상대 정보를 넣으면 성격·생활·기운 보완·운명 지수·띠 궁합 5가지로 100점 만점 점수,
  강점·주의점, 커플 처방전, 둘이 함께 운이 좋은 달
- **상담실** — 묘연에게 계속 질문할 수 있는 채팅. 모든 답변은 사주 근거 + **💡 해결책**으로 끝나요.
  고백 길일, 재회 시기, 연락 방법, 결혼운 등 주제별로 답하고, 궁합을 본 뒤엔 궁합 결과까지 반영해요.

## 실행

```bash
npm install
npm start            # http://localhost:3000
```

API 키 없이도 모든 기능이 동작해요(상담실은 사주 데이터 기반 규칙형 상담).
Claude가 자유롭게 답하는 **AI 상담**을 켜려면 키를 넣고 실행하세요.

```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | 있으면 상담실이 Claude로 답변 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 상담에 쓸 모델 |
| `CLAUDE_EFFORT` | `low` | 답변 깊이 (`low`·`medium`·`high`) — 채팅은 빠른 응답을 위해 `low` |
| `PORT` | `3000` | 서버 포트 |

AI 상담은 스트리밍으로 답하고, 정책상 거절이 나면 서버 측 대체 모델(`fallbacks: "default"`)로 이어 답해요.
AI 호출이 실패하면 화면은 자동으로 규칙형 상담으로 답해요. IP당 분당 15회로 요청을 제한해요.

`public/` 폴더만으로도 정적 사이트로 동작하므로 GitHub Pages·Netlify 등에 그대로 올릴 수 있어요
(이 경우 AI 상담 없이 규칙형 상담만 사용).

## 사주 계산 방식

- **연주·월주**: 태양 황경으로 절기를 직접 계산 (VSOP87 축약식, 1901~2099년 절기 시각 오차 1분 이내)
- **일주**: 율리우스일 기준 60갑자, 자시(23:30 KST) 시작 시 다음 날로 넘김
- **시주**: 동경 127.5° 지방평균시 기준(자시 23:30~01:29), 오서둔법
- **한국 시간대 보정**: 1954~61년 UTC+8:30, 1948~51·1955~60·1987~88년 서머타임 자동 반영
- **음력**: 삭(신월)과 중기를 한국 표준시로 계산해 윤달까지 변환 (1997·2027년처럼 중국 음력과 다른 해도 한국 기준)
- 시간을 모르면 시주 없이 6글자로 풀이해요. 그날 절기가 바뀌면 화면에 안내해요.

## 구조

```
server.js            정적 파일 + /api/chat (Claude 스트리밍) + /api/health
public/index.html
public/css/style.css
public/js/saju.js     절기·간지·십신·지지 관계 계산
public/js/lunar.js    한국 음력 ↔ 양력
public/js/reading.js  연애 풀이 내용, 연애운 점수
public/js/compat.js   궁합
public/js/counsel.js  규칙형 연애 상담
public/js/characters.js  묘연·코코 SVG 캐릭터 (표정 10종)
public/js/app.js      화면(웹툰 패널, 신청서, 상담실)
```

입력한 정보는 브라우저 localStorage에만 저장돼요. AI 상담을 켜면 질문과 사주 요약이 답변 생성을 위해 서버와 Anthropic API로 전송돼요.

> 사주 풀이는 재미와 참고용이에요.
